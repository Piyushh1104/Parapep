# ParaPep: Database of Experimentally Validated Antiparasitic Peptides

## Overview

ParaPep is a manually curated database of experimentally validated antiparasitic peptides (APPs). The database provides detailed information about peptide sequences, structures, chemical modifications, biological activities, assay systems, and parasite targets.

Web Server: http://crdd.osdd.net/raghava/parapep/

## Background

Parasitic diseases are major global health problems. Antiparasitic peptides (APPs) are emerging as promising therapeutic candidates because of:

- High selectivity
- Low toxicity
- Strong antimicrobial activity
- High cell penetration
- Easy chemical modification

ParaPep compiles experimentally validated APPs into a centralized resource.

## Information Available

Each entry includes:

- Peptide name
- Amino acid sequence
- Chirality
- Linear/cyclic topology
- Chemical modifications
- Antiparasitic activity
- Assay information
- Parasite type
- Disease type
- Mode of action
- Origin of peptide

---

## Structural Information

Structures were generated using:

- PEPstr
- AMBER 11
- DSSP
- Open Babel

The database includes:

- Predicted tertiary structures
- Secondary structure information
- SMILES notations
